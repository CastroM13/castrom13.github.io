Como funciona

Um parser determinístico renderiza a fonte em uma prévia isolada; o PDF direto com layout de texto é criado localmente com pdf-lib e a impressão preserva a prévia HTML estilizada.

O caminho LaTeX é um subconjunto prático documentado, não um TeX completo; o PDF direto limita a fonte a 500.000 caracteres e representa imagens pelo texto alternativo, enquanto imagens estilizadas usam a impressão do navegador.
