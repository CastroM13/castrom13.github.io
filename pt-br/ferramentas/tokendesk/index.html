Como funciona

Decodificar não é verificar. O TokenDesk mantém essa distinção no resultado, usa Web Crypto quando uma JWK compatível é fornecida e exporta apenas metadados permitidos — nunca os valores decodificados dos claims.

Feito para inspeção, resposta a incidentes e depuração — não para tomar decisões de autorização.
