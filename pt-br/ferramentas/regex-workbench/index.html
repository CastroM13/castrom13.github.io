Como funciona

Entradas UTF-8 integrais de até 64 MiB rodam em worker descartável, preservando matches arbitrários entre linhas e retendo no máximo 10.000 resultados.

O dialeto é RegExp JavaScript moderno; o worker é encerrado à força após o limite de tempo para conter padrões catastróficos.
