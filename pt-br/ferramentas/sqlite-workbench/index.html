Como funciona

Os bytes permanecem locais; a bancada distingue inspeção estrutural de operações que exigem runtime SQLite WASM.

Arquivos WAL, extensões, bancos criptografados, tabelas virtuais e arquivos muito grandes podem exigir SQLite desktop.
