Como ler o resultado

Na WCAG 2.2, texto grande tem pelo menos 24 CSS px, ou cerca de 18,66 CSS px quando está em negrito. Componentes de interface e objetos gráficos significativos geralmente precisam de 3:1 contra cores adjacentes.

Um par aprovado não torna uma interface acessível sozinho. Verifique também foco visível, estados, tipografia, zoom, movimento, semântica e uso real com tecnologias assistivas.
