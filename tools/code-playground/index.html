How it works

C/C++ uses the site-hosted Emception toolchain; Rust uses a site-hosted Rubrc/rustc worker whose compressed compiler and sysroot are cached locally after an explicit first load.

Native toolchains are large and require cross-origin isolation; the Rust workspace targets wasm32-wasip1, has no external crate downloads, and inherits the disclosed limitations of the pre-release Rubrc runtime.
