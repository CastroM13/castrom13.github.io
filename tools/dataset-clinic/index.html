Dataset Clinic

Audit local YOLO folders or COCO JSON for missing labels, invalid boxes, class distribution, byte-identical duplicates, and exact-duplicate leakage between named splits.

How it works

The clinic reports evidence, paths, and counts without rendering private images. Duplicate checks use local SHA-256 hashes.

Class-balance warnings use a fixed 1% heuristic. Structural checks cannot determine whether an annotation is semantically correct.
