SQLite Workbench

Open a SQLite database, validate its header and pages, inspect schema records, run supported local queries, edit rows when the runtime permits, and export a copy.

How it works

Database bytes remain local; the workbench distinguishes structural inspection from operations that require a SQLite WASM runtime.

WAL companions, extensions, encrypted databases, virtual tables, and very large files may require a full desktop SQLite environment.
