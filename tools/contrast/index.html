How to read the result

Under WCAG 2.2, large text is at least 24 CSS px, or about 18.66 CSS px when bold. Interface components and meaningful graphical objects generally need 3:1 against adjacent colors.

A passing pair does not make an interface accessible by itself. Check focus visibility, states, typography, zoom, motion, semantics, and actual assistive-technology use as well.
