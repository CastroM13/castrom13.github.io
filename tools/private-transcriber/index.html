Private Transcriber

Transcribe local audio with a small Whisper model in the browser, include timestamps, and export TXT, VTT, or SRT.

Audio stays local · Model weights are downloaded on first use
Preparing the local tool…

How it works

The first run downloads model weights from Hugging Face. After that, browser caching may reuse them. The selected audio is decoded and processed locally.

Input files are capped at 48 MiB; decoded audio is capped at 3 minutes and an estimated 96 MiB of 16 kHz PCM because decoding is not streamed. Accuracy depends on language, audio quality, speakers, noise, and device support; always review transcripts.
