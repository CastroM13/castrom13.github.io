Estimated search space—
Guidance—

This estimate describes the generator’s search space. It cannot account for how a service stores passwords or for a compromised device.

Format
Character sets

Uses a built-in English list. With 128 possible words, each generated word contributes 7 bits to the estimated search space.

About this generator

Random choices use crypto.getRandomValues() with rejection sampling to avoid modulo bias. At least one character from every selected category is included before the result is securely shuffled.

Do not reuse a generated password. Store it in a reputable password manager and enable multi-factor authentication where available.
