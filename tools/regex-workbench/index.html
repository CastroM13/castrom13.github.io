How it works

Whole UTF-8 inputs up to 64 MiB run in a disposable worker, preserving arbitrary cross-line matches while retaining at most 10,000 results.

The dialect is modern JavaScript RegExp; the worker is forcibly terminated after its wall-time budget to contain catastrophic patterns.
