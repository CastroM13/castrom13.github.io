How it works

Decoding is not verification. TokenDesk shows that distinction throughout the result, uses Web Crypto when a compatible JWK is supplied, and exports only allowlisted metadata—never decoded claim values.

Designed for inspection, incident response, and debugging—not as an authorization decision engine.
