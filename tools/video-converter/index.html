How it works

The primary path uses the vendored FFmpeg WASM codec core; a separately selected MediaRecorder path handles browser-decodable WebM in real time.

FFmpeg input is capped at 192 MiB / 10 minutes and output at 256 MiB; the streaming fallback is capped at 2 minutes and only emits supported WebM.
